## ♟️ Chess

A complete Low Level Design of a **Chess Game** built in Java.

**Key Design Decisions:**
- Modelled all chess pieces (King, Queen, Rook, Bishop, Knight, Pawn) as separate classes extending a base `Piece` class
- Board represented as an 8x8 grid with clean encapsulation
- Move validation logic handled per piece type
- Strategy Pattern applied for movement rules

## 💬 Stack Overflow

A Low Level Design of the **Stack Overflow** platform built in Java.

**Key Design Decisions:**
- Entities modelled: User, Question, Answer, Comment, Tag, Vote
- Reputation system with upvote/downvote logic
- Observer Pattern for notifications
- Clean separation of concerns with service and model layers

📁 [View Stack Overflow Implementation](https://github.com/harshalsakhare2305/LowLevelDesign/tree/main/Stackoverflow)
